一、接入结论

如果下游已经按照火山方舟官方视频生成文档开发，可继续使用官方的 model + content[] 请求和任务查询方式，只需将火山地址替换为星域互联地址，并将火山 API Key 替换为星域互联 API Key。

API 基础地址：https://api.dkby.com

视频生成与任务查询支持这种仅替换配置的接入。素材库 Action 接口也支持火山 V4 HMAC-SHA256 请求形态，但应使用“豆包视频 → 访问密钥”中生成的独立 Access Key ID 和 Secret Access Key，不使用普通视频 Bearer Token。

五、素材库和 asset://

需要重复使用已审核素材时，可在控制台“豆包视频 → 素材库”创建 AIGC 素材组并上传图片、视频或音频。素材状态变为 Active 后，页面会显示 asset://<Id>。

{
  "type": "image_url",
  "image_url": {"url": "asset://asset-..."},
  "role": "reference_image"
}

素材只能由其所有者使用；一个请求中的素材必须来自同一上游渠道。未审核、属于其他用户或跨渠道混用的素材会被拒绝。

火山 Action 兼容入口

官方 SDK 推荐使用根路径；控制台复制的访问密钥页面还提供等价的 /api/doubao-video/openapi 兼容路径。

POST https://api.dkby.com/?Action=CreateAssetGroup&Version=2024-01-01
Authorization: HMAC-SHA256 Credential=AKLT.../<date>/cn-beijing/ark/request, SignedHeaders=content-type;host;x-content-sha256;x-date, Signature=<64位十六进制签名>
X-Date: <UTC yyyyMMddTHHmmssZ>
X-Content-Sha256: <最终发送请求体的 SHA-256>
Content-Type: application/json
POST https://api.dkby.com/api/doubao-video/openapi?Action=CreateAssetGroup&Version=2024-01-01
Authorization: HMAC-SHA256 Credential=AKLT.../<date>/cn-beijing/ark/request, SignedHeaders=content-type;host;x-content-sha256;x-date, Signature=<64位十六进制签名>
X-Date: <UTC yyyyMMddTHHmmssZ>
X-Content-Sha256: <最终发送请求体的 SHA-256>
Content-Type: application/json

根路径 / 与 /api/doubao-video/openapi 均受支持。签名时 CanonicalURI 必须使用实际发送的请求路径，不要发送一个路径却按另一个路径生成签名。Action 和 Version 组成规范查询串，按名称排序并进行 URL 编码；示例结果为 Action=CreateAssetGroup&Version=2024-01-01。

手动实现签名时，SignedHeaders 至少必须是按小写字典序排列的 content-type;host;x-content-sha256;x-date；Host 只填写 api.dkby.com，不要填写 https:// 或凭空添加端口；X-Content-Sha256 必须对最终发送的请求体字节计算，计算后不要再次序列化 JSON；X-Date 使用 UTC 格式且请求时间须在服务端前后 5 分钟内。

签名密钥派生顺序为 dateKey = HMAC(SK, YYYYMMDD)、regionKey = HMAC(dateKey, cn-beijing)、serviceKey = HMAC(regionKey, ark)、signingKey = HMAC(serviceKey, request)。CanonicalRequest 按换行依次包含 HTTP 方法、规范 URI、规范查询串、规范请求头、SignedHeaders 和请求体 SHA-256；最终使用 signingKey 对 HMAC-SHA256\nX-Date\n<date>/cn-beijing/ark/request\nSHA256(CanonicalRequest) 计算签名。

目前支持 CreateAssetGroup、ListAssetGroups、CreateAsset、GetAsset、ListAssets 和 DeleteAsset。下游使用火山官方 SDK 时，需要把 Endpoint 换成星域互联域名，并把 AK/SK 换成星域互联素材访问密钥。调用其他火山素材 Action 前请先确认本页支持列表。

CreateAsset 是异步操作。返回 ID 不代表素材已经可用，必须轮询 GetAsset，仅 Status=Active 后才能用于生成。

六、媒体输入方式

  • 火山原生接口和 /v1/video/generations 使用 JSON，可传稳定 HTTP(S) URL、数据 URL、纯 Base64 或 asset://；
  • /v1/videos 额外支持名为 input_reference 的 multipart 文件；
  • 可通过 /v1/video-inputs/presign 与 /v1/video-inputs/complete 进行客户端直传。

公网 URL 应无需 Cookie、登录态或自定义请求头，在任务完成前持续有效，并返回正确的媒体 Content-Type。生产环境优先使用稳定 HTTPS URL、素材库引用或客户端直传。

未启用媒体外置时，Base64 会直接进入上游 JSON；过大的内联请求可能返回 HTTP 413。不要把大型视频或音频作为 Base64 放入 JSON。

七、查询任务与读取视频

火山原生查询

GET https://api.dkby.com/api/v3/contents/generations/tasks/{task_id}
Authorization: Bearer sk-your-starnexus-api-key

统一接口查询

GET https://api.dkby.com/v1/video/generations/{task_id}

建议每 2～5 秒查询一次。常见处理中状态包括 queued、SUBMITTED、in_progress 和 RETRYING。遇到 RETRYING 应继续等待，不要重复创建任务。

读取视频内容

GET https://api.dkby.com/v1/videos/{task_id}/content

内容接口需要 API Key 或有效登录态，并支持 HTTP Range，可用于断点下载和播放器拖动。

八、限制、错误与接入建议

  • Seedance 2.0、Fast、Mini 当前网关校验的最长时长为 15 秒；Seedance 2.5 最长为 30 秒；通常最低为 4 秒，具体仍以实时模型能力为准。
  • 入口常见图片格式包括 JPEG、PNG、WebP、GIF；模型上游可能有更严格的尺寸、比例和内容要求。
  • 创建请求超时且没有收到完整响应时，不要立即重放，以免形成重复计费任务。
  • 创建成功后立即保存返回的公开任务 ID；不要依赖或猜测内部任务 ID。

StarNexus Doubao Seedance Video and Asset Guide

Use the Volcengine Ark Seedance request shape with StarNexus by replacing the service URL and credentials.

Ark-compatible pathsOpenAI Videosasset:// references

1. Compatibility

Clients implemented against the official Ark video-generation documentation can keep the model + content[] body and polling flow. Replace the Ark URL with https://api.dkby.com and use a StarNexus API key.

Video submission and polling work with configuration-only replacement. Asset Actions use separate HMAC-SHA256 AK/SK credentials created under “Doubao Video → Access Keys”.

Authorization: Bearer sk-your-starnexus-api-key
Content-Type: application/json

{"model":"doubao-seedance-2-0-260128","content":[{"type":"text","text":"A fixed camera shot"}],"duration":5}

Poll with GET /api/v3/contents/generations/tasks/{task_id}. StarNexus also provides POST /v1/video/generations and OpenAI-compatible POST /v1/videos.

4. Asset library

After an asset reaches Active, reference it as asset://<asset_id> in the official content[] structure.

Use the root path with official SDKs, or the equivalent console path shown on the Access Keys page.

POST https://api.dkby.com/?Action=CreateAssetGroup&Version=2024-01-01
Authorization: HMAC-SHA256 Credential=AKLT.../<date>/cn-beijing/ark/request, SignedHeaders=content-type;host;x-content-sha256;x-date, Signature=<64-hex signature>
X-Date: <UTC yyyyMMddTHHmmssZ>
X-Content-Sha256: <SHA-256 of the exact request body bytes>
Content-Type: application/json
POST https://api.dkby.com/api/doubao-video/openapi?Action=CreateAssetGroup&Version=2024-01-01

Both paths are supported, but CanonicalURI must match the path actually sent. Use the exact sorted signed-header list content-type;host;x-content-sha256;x-date, sign Host: api.dkby.com, and hash the final body bytes without re-serializing JSON. Keep X-Date in UTC and within five minutes of server time. The signing-key chain is dateKey → regionKey → serviceKey → signingKey for YYYYMMDD, cn-beijing, ark, and request. Supported Actions: CreateAssetGroup, ListAssetGroups, CreateAsset, GetAsset, ListAssets, and DeleteAsset. CreateAsset is asynchronous; poll until Status=Active.

5. Inputs, status, and content

JSON endpoints accept stable HTTP(S) URLs, data URLs, plain Base64, and owned asset:// references. /v1/videos additionally accepts a multipart input_reference. Poll every 2–5 seconds and keep waiting during RETRYING.

GET https://api.dkby.com/v1/videos/{task_id}/content

The content endpoint requires an API key or authenticated session and supports HTTP Range.
