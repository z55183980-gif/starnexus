# Messages 首字显示与 Sub2API 对齐

2026-10-18，按用户要求，StarNexus Messages 首字显示采用 Sub2API 现有口径：

- 有合法生成时间回执：使用回执还原的生成首字时间。
- 没有生成时间回执：使用首个非空 SSE data 事件到达时间，包括 ping 和 message_start。
- 下游正文/工具内容交付时间不覆盖首字显示。

这替代 174cba245 引入的 downstream_content 显示优先级。两层各自从请求起点计时，因此会有请求准备与网络传输的少量差值；并非复制另一个数据库的毫秒值。

本次只改变日志显示值的选择，不改 Sub2API、Wrapper 缓冲、流终止处理、重试、计费或缓存。历史日志不回填。生产仅发布 S2。
